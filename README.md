# Sitio web U.E. Constantino I

Sitio estático para GitHub Pages. Sin build: se edita y se publica tal cual.

- `index.html` – estructura y textos
- `css/styles.css` – estilos (verde institucional, dorado de acento)
- `js/main.js` – carrusel, pestañas de niveles, carga de noticias
- `data/noticias.json` – comunicados (luego se llenará desde una planilla de Google)
- `assets/` – escudo y, más adelante, fotos

Pendientes marcados con `PENDIENTE` en `index.html`.
